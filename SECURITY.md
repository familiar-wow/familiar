# Security policy

Familiar is in pre-alpha. Only the latest state of `main` receives fixes.

Please report vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/familiar-wow/familiar/security/advisories/new), not in public issues. We aim to reply within a week.

We especially want to hear about:

- API keys or other secrets leaking from the app, logs or saved variables
- game text that makes a brain act outside Familiar's advisory role
- code execution through the transport between addon and companion
- tampering with updates or installers
